# Simjay Tap

## How do I install these formulae?

`brew install simjay/tap/<formula>`

Or `brew tap simjay/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "simjay/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
